# Support

Support is best effort through [GitHub Issues](https://github.com/BenDManning/jetkvm-mcp/issues).
There is no SLA, long-term-support line, or blanket backport commitment. Please
reproduce a problem on the latest stable release before requesting support.
Support does not certify deployments or promise that any JetKVM model, firmware,
attached host, or FFmpeg combination is physically compatible.

For a bug or compatibility report, provide the JetKVM MCP version, operating
system and architecture, transport, exact operation, expected result, and
sanitized reproduction. A physical-compatibility report should also identify
the JetKVM model and firmware and the relevant FFmpeg version. Never include
credentials, device addresses, private paths or URLs, screenshots, device data,
or unsanitized logs.

Use the private route in [`SECURITY.md`](SECURITY.md) for suspected
vulnerabilities. Product scope, supported surfaces, and qualification limits are
defined in [`docs/product-contract.md`](docs/product-contract.md).
